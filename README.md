# Weather Dashboard

## Project Summary
This is an interactive weather dashboard built with React and Vite. Users can search for a city to view current weather, save recent searches, and switch temperature units.

## Key Features
- Search weather by city
- Current temperature and wind speed
- Units toggle (°F / °C)
- Recent searches (saved with localStorage)
- Loading and error messages

## Technologies Used
- React
- Vite
- JavaScript
- HTML/CSS
- Open-Meteo API
- GitHub Pages

## How to Use
1. Type a city name and click Search.
2. Click a recent city to search again.
3. Click Clear to remove recent searches.
4. Click the Units button to switch between °F and °C.
